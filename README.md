# Bronco Life Skills

Eleven complete lesson plans for the Middleburg Lady Broncos Life Skills Mentorship series, November 2026 through January 2027.

Open `index.html` in any browser, or turn on GitHub Pages (Settings, Pages, deploy from this branch, root folder) to get a link the whole staff can use.

## What each lesson includes

* Game plan bar showing how the 20 to 30 minutes are split
* Opening hook to grab attention
* Teaching points for every line item in the curriculum, with coach tips
* Key terms
* Numbers that matter, with sources
* Video picks (YouTube searches to preview before class) and trusted resources
* A hands on activity with steps, materials, debrief questions, a built in timer, and handouts
* Interactive tools (budget builder, compound growth, grocery cart, decision matrix, profit calculator)
* Take home challenge, discussion starters, and coach notes
* Present mode: one click turns the lesson into big slides for a TV or projector (arrow keys to move)

## Editing content

All lesson text lives in `assets/lessons.js`. Change a presenter, a stat, or an activity there and refresh the page.
